For students of Langchain and Agentic Frameworks. Repo should highlight some basic functionality of Langchain, Langgraph, and Langsmith.

2. For each of Langchain and Langgraph, create a basic agent that can write answers to file in `./output/` folder, when requested by the user.

Use astral.sh/uv (already installed)
